# 🧩 Sudoku Board (C#)

A simple **Sudoku board implementation** written in **C#**.  
It includes a `Sudoku` class that represents the Sudoku grid with validation features, formatted printing.

---

## ✨ Features

- ✅ Boundary check before setting values.  
- 🔒 Prevents modification of original (pre-filled) cells.  
- 🧮 Validate a specific row, column, or 3×3 box.  
- 🎨 Beautiful formatted console printing.  
- ⚡️ Clean, well-documented, and object-oriented C# code.
